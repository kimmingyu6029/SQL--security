로그인 입력

취약한 페이지와 같은 값을 입력해 결과를 비교하세요.

SQL문과 파라미터 분리

query = (
    "SELECT * FROM users "
    "WHERE username = ? "
    "AND password = ?"
)
cursor.execute(
    query,
    (username, password)
)
