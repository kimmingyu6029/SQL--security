SQL Injection에 취약한 로그인

입력값을 문자열 연결로 SQL문에 직접 포함하는 교육용 예제입니다.

교육용 취약 코드

이 구현 방식은 실제 서비스에서 사용하면 안 됩니다. 반드시 이 로컬 실습 환경에서만 확인하세요.

문자열 연결 방식

로그인 입력

실험 결과 비교를 위해 입력값을 그대로 표시합니다.

서버에서 만드는 SQL문

query = (
    "SELECT * FROM users "
    "WHERE username = '" + username +
    "' AND password = '" + password + "'"
)

따옴표나 주석 기호가 포함된 입력은 단순한 값에 머물지 않고, SQL문의 조건 구조에 영향을 줄 수 있습니다.
